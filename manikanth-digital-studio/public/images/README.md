# Image Assets

## Required Images (Enterprise Standard)
- All images must be WebP or AVIF format
- Max width: 1920px for hero, 1200px for portfolio
- Compressed with sharp: ~300KB hero, ~150KB portfolio items
- Include blur LQIP placeholders for lazy loading

## Placeholder Strategy
Until real studio photography is added, use high-quality Unsplash URLs with `?auto=format&fit=crop` parameters. Replace with local assets before production launch.
