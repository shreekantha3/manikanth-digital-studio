# Manikanth Digital Studio — Claude Code Guidance

## Project Overview

Premium photography website for Manikanth Digital Studio, Sindagi, Karnataka.
React 18 + TypeScript + Vite 5 + Tailwind CSS 3 + Framer Motion + Lucide React.

Deployed to:
- GitHub Pages: `https://shreekantha3.github.io/manikanth-digital-studio/`
- Vercel: `https://manikanth-digital-studio.vercel.app/`

## Key Architecture

- **Entry Point**: `index.html` → `<script src="src/main.tsx">` (Vite injects chunk paths during build)
- **Build Output**: `dist/` directory (NOT gitignored — built files are pushed to `main`)
- **Base Path**: `/manikanth-digital-studio/` (for GitHub Pages subpath)
- **Vite Config**: `vite.config.ts` with `base: '/manikanth-digital-studio/'`, `input: 'index.html'`, `entryFileNames: 'index-[hash].js'`
- **Chunk Splitting**: `vendor` (react, react-dom), `motion` (framer-motion), `icons` (lucide-react)

## Build Command

```bash
VITE_BASE=/manikanth-digital-studio/ npm run build
```

## Critical Dependencies

- `@emotion/is-prop-valid: ^1.3.0` — **REQUIRED** peer dependency of `framer-motion` v11. Never remove it.
- `framer-motion: ^11.11.17` — Uses `@emotion/is-prop-valid` internally.

## Deployment Workflow

1. `index.html` is a clean template — NO hardcoded script/link paths
2. Vite injects `<script src="/manikanth-digital-studio/index-[hash].js">` during build
3. Built `dist/` files are pushed to `main` branch (not gitignored)
4. GitHub Pages `build_type: "legacy"` serves raw files from `main`
5. Vercel deploys from the repo — may cache aggressively (purge cache after updates)

## Common Mistakes to Avoid

1. **Never hardcode chunk hashes in `index.html`** — Vite generates these during build. If `index.html` has stale `<link>` tags, Vite's HTML parser breaks and produces empty chunks.
2. **Never remove `@emotion/is-prop-valid`** — This is a required peer dependency of `framer-motion` v11. Without it, the app shows a blank white page.
3. **Never put `dist/` in `.gitignore`** if deploying built files — The built `dist/` files must be on `main` for GitHub Pages to serve them.
4. **Never use `gh api` PUT/PATCH on `.github/workflows/deploy.yml`** — Returns 404. Use `git push` instead.
5. **OAuth token lacks `workflow` scope** — Cannot push `.github/workflows/` via git.
6. **Vercel caches aggressively** — `x-vercel-cache: HIT` can serve stale content. Need to purge cache in Vercel dashboard.
7. **Never use `git push --force`** on remote `main` — Can orphan commits. Use the Git API to create a new commit.

## GitHub Pages Configuration

- `build_type: "legacy"` — serves raw files from `main` branch
- Cannot be changed to `github_actions` via API (returns 404)
- `deploy.yml` auto-deploys on push to `main` using `actions/upload-pages-artifact@v3` and `actions/deploy-pages@v4`
- `pages-build-deployment` is auto-generated by GitHub — may upload source files without building if `build_type: "legacy"`

## Testing

Run `npm run build` locally before pushing. Verify all chunks load with `curl -sI` on GitHub Pages URLs.
